I'm a frontend engineer. I work mostly with Angular, and with TypeScript and Astro when the job fits. I care about developer experience, performance, and making a tool that another developer would actually enjoy using. What I find interesting is tooling, developer productivity, and a UX that people actually like. The side projects stay small.

[snipsco.com](https://snipsco.com) is code snippets made easy, built entirely with Angular. There was no plan for it. I asked for an Angular prototype, it did a better job than I expected, and I turned that into a real app. I wrote that up in <a href="/blog/snipsco">how Snipsco happened</a>. The workspace there stays free, with no limits, because I remember what it felt like to hit a limit in someone else's tool and I didn't want that for people sharing code. [quiky.email](https://quiky.email) is free email writing tools, built with Astro. [tailwind-astro-starting-blog](https://github.com/wanoo21/tailwind-astro-starting-blog) is an Astro and Tailwind blog starter that a lot of people use. I share a lot of code examples, tricks and bits of code that made me laugh or just made me sad, and Snipsco came out of that habit. I've been a frontend developer for a long time. Back when I started, table layouts were how a page got built, so I'm a senior developer still trying to keep a foot in how fast AI coding is changing. I didn't use to think of myself as an indie hacker. These are the small things I ship anyway. When I'm not building, I'm usually thinking about how to improve a tool I already have. This blog is where I write that down. Mostly frontend, sometimes the shape of a project, sometimes something that will not fit in a tweet.

[OldPics](https://oldpics.ai) is the side project after those. I kept the choices few.

I kept it narrow. One job. No account. Each device gets 5 free restores, and after that the next restores are a one-time pack instead of a subscription, $9 for 20 or $29 for 100. I didn't want the project to turn into signup, passwords, and a plan that bills again next month. What those free restores include is on [restore old photos free](https://oldpics.ai/restore-old-photos-free).

I built it in Angular with server-side rendering, on Cloudflare Workers, because that is what I already use. Snipsco is Angular. Quiky and the blog starter are both Astro, which is the other thing I work in. A tool that is one page, drop a photo, restore it, download it, did not need a new framework. I stayed in the stack I already ship with.

A soft or blurry scan stays soft. It does not invent detail that was never in the photo.
