This week is mostly **Safari 27** landing for real, plus a **Baseline newly** wave that finally catches several features Safari just made universal. Chrome **154** and Edge **154** are out on the two-week train; Firefox 156 is the quiet but useful mid-month release.

## Safari 27.0 (17 Sep) — quality first, then a long feature list

[WebKit’s Safari 27 notes](https://webkit.org/blog/18325/webkit-features-for-safari-27-0/) are the longest they’ve shipped. The headline isn’t a single shiny API — it’s **844 fixes**, a rebuilt ES module loader, subpixel inline layout, and a pile of SVG / MSE / table work. If something “weird only in Safari” has been biting you, this is the release to re-test against.

A few features that matter for day-to-day frontend work:

### Scroll anchoring is finally everywhere

Safari 27 turns on **scroll anchoring** by default. When content injects above the viewport (lazy images, ads, comments), the scroll position adjusts so what you were reading doesn’t jump.

You usually do nothing. Opt out with:

```css
.skip-anchoring {
  overflow-anchor: none;
}
```

**Baseline:** [overflow-anchor](https://developer.mozilla.org/en-US/docs/Web/CSS/overflow-anchor) is **Baseline 2026 newly available** (since September 2026) per MDN / [webstatus.dev](https://webstatus.dev/?q=baseline_status:newly). Vendor: [WebKit Safari 27](https://webkit.org/blog/18325/webkit-features-for-safari-27-0/).

### Customizable `<select>` in Safari (not Baseline yet)

`appearance: base-select` on the control and picker lets you restyle a real `<select>` — keyboard, a11y, form submission included — instead of rebuilding a listbox in JS:

```css
select,
select::picker(select) {
  appearance: base-select;
}
```

Safari 27 also refreshed the UA defaults (cheaper starting point than the June beta).

**Status:** Chromium shipped this earlier; Safari 27 joins. [webstatus.dev](https://webstatus.dev/features/customizable-select) still lists **customizable-select** as **limited** (Safari 27 is on the board; Firefox is not). **Do not call this Baseline.** MDN: [Customizable select](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Forms/Customizable_select) · [appearance](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/appearance). Vendor: [WebKit](https://webkit.org/blog/18325/webkit-features-for-safari-27-0/).

### Top-level `await` — fixed, not “newly invented”

Safari had top-level `await` for a while; it was a known source of “accessed before initialization” bugs. Safari 27 **rewrote the ES module loader** for spec compliance. Details: [Fixing Top-Level Await in Safari](https://webkit.org/blog/18320/fixing-top-level-await-in-safari/) (2 Sep) and the [Safari 27 feature post](https://webkit.org/blog/18325/webkit-features-for-safari-27-0/).

**Baseline:** [webstatus.dev](https://webstatus.dev/?q=baseline_status:newly) marks **top-level-await** as **newly** as of **2026-09-14** (Safari’s correctness landing closes the practical gap). MDN’s general [`await`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/await) page stays “widely available” with a support caveat — use webstatus + the WebKit post when you talk about the fix.

### WebAssembly JSPI in Safari

Safari 27 adds **JavaScript Promise Integration**: Wasm can suspend on a Promise and resume, which matters a lot for porting sync-looking C/C++/Rust I/O to the web.

BCD Watch’s week of 14–21 Sep recorded Safari picking up `WebAssembly.Suspending`, `SuspendError`, and `promising` — **3 of 3 engines** on BCD (remember: 3-engine on BCD Watch is **not** automatically Baseline).

**Baseline:** [wasm-jspi](https://webstatus.dev/?q=baseline_status:newly) is **newly** as of **2026-09-14** on webstatus.dev. MDN: [`WebAssembly.Suspending`](https://developer.mozilla.org/en-US/docs/WebAssembly/Reference/JavaScript_interface/Suspending) (badge may still lag — trust webstatus for the newly date). Vendor: [WebKit](https://webkit.org/blog/18325/webkit-features-for-safari-27-0/).

### Safari MCP (tooling, Safari-only)

Safari 27 ships a local **MCP server** via `safaridriver --mcp` so coding agents can drive DOM, network, screenshots, and console on your machine. Useful if you live in agent workflows — **not a web-platform Baseline story**. Intro: [Introducing the Safari MCP server](https://webkit.org/blog/18136/introducing-the-safari-mcp-server-for-web-developers/).

Also Safari-only / early for most sites: HTML `<model>` on iOS/iPadOS/macOS, immersive environments on visionOS — label **Safari / spatial web**, not “works now everywhere.”

## Firefox 156 (stable, 15 Sep)

[MDN Firefox 156 notes](https://developer.mozilla.org/en-US/docs/Mozilla/Firefox/Releases/156) — a maintenance-shaped release for most frontend folks:

- **`::-webkit-scrollbar` in `@supports`**: Firefox now reports the pseudo as *unsupported* in `@supports` everywhere (even on the fake-webkit-scrollbar allowlist domains). Sites that gate *standard* scrollbar styles behind `@supports not (selector(::-webkit-scrollbar))` finally get those styles in Firefox. Subtle, but it unblocks a lot of “Chrome-looking scrollbar CSS” paths.
- **`text-box-trim` / `text-box-edge`** correctness fixes (still no effect with `line-clamp`).
- Spec alignment: `Promise.try()` pass-through, `using` bindings non-reassignable, `Range.deleteContents` / `extractContents` on the DOM tree (not flat tree) across shadow boundaries.

**Experimental / Nightly-flagged** (do not ship as “works now”): scoped custom element registries (on by default in Nightly), `named-feature()` in `@supports`, Container Timing API.

Firefox **157** ships **Tue 29 Sep** — [MDN 157 notes](https://developer.mozilla.org/en-US/docs/Mozilla/Firefox/Releases/157) are still WIP; early note: `@supports at-rule(@scope)` via `at-rule()`.

## Chromium / Edge — 154 is out

Chrome **154** hit stable **22 Sep** ([New in Chrome 154](https://developer.chrome.com/blog/new-in-chrome-154), [release notes](https://developer.chrome.com/release-notes/154)). Edge **154** followed **24 Sep** ([learn.microsoft.com](https://learn.microsoft.com/en-us/microsoft-edge/web-platform/release-notes/154)). That’s the second stop on the two-week train that started with Chrome **153** (8 Sep) / Edge **153** (10 Sep): [cadence announcement](https://developer.chrome.com/blog/chrome-two-week-start).

### 154 highlights (Chromium-family — not Baseline)

**Responsive iframes** — drop the `postMessage` height dance. On the embed: `frame-sizing: content-height`. The child opts in with `<meta name="responsive-embedded-sizing" content="allow-origins=*">`. MDN: [`frame-sizing`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/frame-sizing) is **limited**; [`responsive-embedded-sizing`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/meta/name/responsive-embedded-sizing) same. **Not Baseline.** Vendors: [Chrome 154](https://developer.chrome.com/blog/new-in-chrome-154), [Edge 154](https://learn.microsoft.com/en-us/microsoft-edge/web-platform/release-notes/154).

**`scroll-marker-group` modes** — `links` (default, nav-list semantics) and `tabs` (tablist / tab / tabpanel). Focus order and a11y roles follow the mode:

```css
scroll-marker-group: after links;
scroll-marker-group: before tabs;
```

MDN: [`::scroll-marker-group`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/::scroll-marker-group) is **limited**. **Not Baseline.**

**`text-decoration-inset`** — shorten, lengthen, or shift underlines without fake background tricks. `10px` insets both ends; two values set start/end independently. MDN: [`text-decoration-inset`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/text-decoration-inset) (experimental; no Baseline badge). **Not Baseline.**

**Edge extras on the same train** (also Chromium 154): [`Iterator.includes`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Iterator/includes) — `someIterator.includes(value)`, same idea as `Array.includes`. **`font-width`** as the `@font-face` / `FontFace` alias for `font-stretch` ([MDN descriptor](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@font-face/font-width) is **limited**). CSS Typed OM constructors (`CSSStyleValue`, `CSSNumericValue`, …) now work in workers — Edge says this matches Firefox/Safari. None of these are Baseline on webstatus as of 27 Sep.

### Still from 153 (if you skipped last cycle)

**Single-axis scroll containers** — `overflow: scroll clip` (and friends) so one axis scrolls and the other clips; unlocks sticky header/column patterns. Chrome’s “New in 153” post said this was for **non-stable channels** in 153; Edge 153 listed it in the shipping notes. Treat as **Chromium-family, verify channel** — **not Baseline**. MDN: [`overflow`](https://developer.mozilla.org/en-US/docs/Web/CSS/overflow). Vendors: [Chrome 153](https://developer.chrome.com/blog/new-in-chrome-153), [Edge 153](https://learn.microsoft.com/en-us/microsoft-edge/web-platform/release-notes/153).

Related Chromium work (CSS-Tricks Nightly ticker / Edge notes): **`scroll-axis-lock`** (`auto` | `none`) to allow or constrain diagonal scroll locking — **Edge 153 lists it**; still **single-engine / early**, not Baseline. MDN may still be thin — caveat **not fully documented on MDN yet** if the page is missing.

**`<camera>` and `<microphone>` capability elements** — declarative, browser-styled buttons that request a single media capability (video or audio), in the same security model as the earlier multi-capability usermedia control. **Chromium-only** for now (Chrome/Edge 153). Vendor: [Chrome 153 release notes](https://developer.chrome.com/release-notes/153), [Edge 153](https://learn.microsoft.com/en-us/microsoft-edge/web-platform/release-notes/153). **Not in MDN as a multi-engine Baseline feature yet** — treat as experimental / single-engine.

**`Iterator.zip()` / `Iterator.zipKeyed()`** — Joint Iteration. MDN: [Iterator.zip()](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Iterator/zip). Shipping in Chrome/Edge 153; **not Baseline** until the other engines catch up.

CSS-Tricks’ Nightly/Canary ticker (ticker only, never Baseline): Safari TP 252 trials `named-feature()`; Firefox Nightly notes around `overscroll-behavior: chain`; Chrome Canary/Dev chatter on `random()` / `scroll-axis-lock`. Fun to poke, **not “works now.”**
