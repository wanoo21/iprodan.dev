    <h2 class="text-2xl font-semibold text-neutral-900 dark:text-neutral-100">What does it do?</h2>
    <p class="text-neutral-600 dark:text-neutral-400 leading-relaxed">
      <code class="text-purple-600 dark:text-purple-300 bg-purple-50 dark:bg-purple-900/50 px-1.5 py-0.5 rounded">display: grid-lanes</code> packs mixed-height items so the next one fills the shortest column — no empty row gaps. Column count still comes from <code class="text-purple-600 dark:text-purple-300 bg-purple-50 dark:bg-purple-900/50 px-1.5 py-0.5 rounded">grid-template-columns</code>. The snippet above is the whole API — made in <a href="/blog/snipsco" class="inline whitespace-nowrap text-purple-600 dark:text-purple-300 underline font-mono text-sm px-1.5 py-0.5 rounded bg-purple-50 dark:bg-purple-900/50">Snipsco</a>.
    </p>

    <h2 class="text-2xl font-semibold text-neutral-900 dark:text-neutral-100"><code>columns</code> vs <code>grid-lanes</code></h2>
    <p class="text-neutral-600 dark:text-neutral-400 leading-relaxed">
      <code class="text-purple-600 dark:text-purple-300 bg-purple-50 dark:bg-purple-900/50 px-1.5 py-0.5 rounded">columns:</code> is a newspaper: items fill <strong>down</strong> the first column, then the next. Tab order follows that. <code class="text-purple-600 dark:text-purple-300 bg-purple-50 dark:bg-purple-900/50 px-1.5 py-0.5 rounded">grid-lanes</code> is Pinterest: items fill <strong>across</strong>, always into the shortest column, so tab order stays with what’s on screen.
    </p>
    <p class="text-neutral-600 dark:text-neutral-400 leading-relaxed">
      Use <code class="text-purple-600 dark:text-purple-300 bg-purple-50 dark:bg-purple-900/50 px-1.5 py-0.5 rounded">grid-lanes</code> for card and image boards. Use <code class="text-purple-600 dark:text-purple-300 bg-purple-50 dark:bg-purple-900/50 px-1.5 py-0.5 rounded">columns:</code> for actual text columns, and as the fallback until <code class="text-purple-600 dark:text-purple-300 bg-purple-50 dark:bg-purple-900/50 px-1.5 py-0.5 rounded">grid-lanes</code> is everywhere.
    </p>

    <h2 class="text-2xl font-semibold text-neutral-900 dark:text-neutral-100">Fallback</h2>
    <p class="text-neutral-600 dark:text-neutral-400 leading-relaxed">
      Start with <code class="text-purple-600 dark:text-purple-300 bg-purple-50 dark:bg-purple-900/50 px-1.5 py-0.5 rounded">columns:</code> and <code class="text-purple-600 dark:text-purple-300 bg-purple-50 dark:bg-purple-900/50 px-1.5 py-0.5 rounded">break-inside: avoid</code> on children. Inside <code class="text-purple-600 dark:text-purple-300 bg-purple-50 dark:bg-purple-900/50 px-1.5 py-0.5 rounded">@supports (display: grid-lanes)</code>, set <code class="text-purple-600 dark:text-purple-300 bg-purple-50 dark:bg-purple-900/50 px-1.5 py-0.5 rounded">columns: unset</code> and switch to <code class="text-purple-600 dark:text-purple-300 bg-purple-50 dark:bg-purple-900/50 px-1.5 py-0.5 rounded">display: grid-lanes</code>.
    </p>
