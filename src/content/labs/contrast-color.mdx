    <h2 class="text-2xl font-semibold text-neutral-900 dark:text-neutral-100">What does it do?</h2>
    <p class="text-neutral-600 dark:text-neutral-400 leading-relaxed">
      <code class="text-purple-600 dark:text-purple-300 bg-purple-50 dark:bg-purple-900/50 px-1.5 py-0.5 rounded">contrast-color()</code> takes a color and returns <code class="text-purple-600 dark:text-purple-300 bg-purple-50 dark:bg-purple-900/50 px-1.5 py-0.5 rounded">white</code> or <code class="text-purple-600 dark:text-purple-300 bg-purple-50 dark:bg-purple-900/50 px-1.5 py-0.5 rounded">black</code>, whichever contrasts more. Tie goes to white. The snippet above is the whole API — made in <a href="/blog/snipsco" class="inline whitespace-nowrap text-purple-600 dark:text-purple-300 underline font-mono text-sm px-1.5 py-0.5 rounded bg-purple-50 dark:bg-purple-900/50">Snipsco</a>.
    </p>
    <p class="text-neutral-600 dark:text-neutral-400 leading-relaxed">
      No luminance helper, no hardcoded text pair. When <code class="text-purple-600 dark:text-purple-300 bg-purple-50 dark:bg-purple-900/50 px-1.5 py-0.5 rounded">--brand</code> changes, the foreground follows. Baseline since April 2026 (Chrome 147, Firefox 146, Safari 26). Spec: <a href="https://drafts.csswg.org/css-color-5/#contrast-color" class="text-purple-600 dark:text-purple-300 underline" target="_blank" rel="noopener">CSS Color Module Level 5</a>. Docs: <a href="https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/color_value/contrast-color" class="text-purple-600 dark:text-purple-300 underline" target="_blank" rel="noopener">MDN</a>.
    </p>
    <h2 class="text-2xl font-semibold text-neutral-900 dark:text-neutral-100">Fallback</h2>
    <p class="text-neutral-600 dark:text-neutral-400 leading-relaxed">
      Gate the declaration with <code class="text-purple-600 dark:text-purple-300 bg-purple-50 dark:bg-purple-900/50 px-1.5 py-0.5 rounded">@supports (color: contrast-color(red))</code>, and keep a hardcoded <code class="text-purple-600 dark:text-purple-300 bg-purple-50 dark:bg-purple-900/50 px-1.5 py-0.5 rounded">color</code> first so older engines still paint text.
    </p>

    <h2 class="text-2xl font-semibold text-neutral-900 dark:text-neutral-100">The mid-tone trap</h2>
    <p class="text-neutral-600 dark:text-neutral-400 leading-relaxed">
      Only black or white, targeting WCAG 2 AA (~4.5:1). Mid-tones lose: <code class="text-purple-600 dark:text-purple-300 bg-purple-50 dark:bg-purple-900/50 px-1.5 py-0.5 rounded">#2277d3</code> picks black, and small text still fails. Keep palettes at the light or dark ends.
    </p>
